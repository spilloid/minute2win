# 2026-11-14 desktop companion validation

- Native Windows vet/tests/race checks passed during development. A native GUI-subsystem executable created its Win32 tray window and menu. An isolated loopback fixture drove idle, armed, running, degraded and unreachable states; actual native menu strings matched each. A duplicate process exited and the Quit command ended the companion. The fixture recorded only GET `/api/state`, without Authorization or Cookie headers. No live target was armed.
- The cropped native menu was inspected at Windows display scaling and saved as `docs/assets/screenshots/tray-menu-windows.png`. All labels fit. Disabled profiles/logs entries correspond to the test's omitted host directory. The native icon loader reported no errors in the companion log.
- Read-only `-check` against the existing host returned online. Release allowlist/draft-only-upload regressions passed against a mock `gh`; shell syntax, site-version, actionlint and diff whitespace checks passed.
- Initial govulncheck found standard-library issues in local Go 1.27.0. Both modules now require Go 1.27.4; validation switched to that current stable patch. The companion scan then reported no vulnerabilities. Platform dependencies are pinned to systray 1.12.2, godbus 5.2.4 and x/sys 0.50.0; license copies ship.
- Astra reviewed only the companion and native packaging/CI changes. Its conditional macOS AppTranslocation finding was fixed by rejecting startup registration before any write, with move/relaunch guidance. Astra confirmed the guard and closed the finding. Its script-permissions concern was withdrawn after checking the staged executable bit.

The platform matrix checks Windows, Linux, macOS Intel and Apple silicon builds/tests. Release jobs additionally smoke-test packaged status polling and verify both Windows executable signatures/timestamps and macOS ad-hoc bundle signatures. These must pass before publication. Graphical macOS/Linux menus and next-login startup have not been observed. macOS is not Developer ID signed or notarized. No new target installation is claimed.
